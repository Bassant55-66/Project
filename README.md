# E-Commerce Backend API

## Overview

This project is a backend API for an e-commerce application built with Flask and Python.

It provides endpoints for managing products, shopping carts, user authentication, and orders.

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Bcrypt
- Flask-CORS
- SQLite (if configured in the project)

## Features

### Products
- Retrieve product information.
- Manage products, depending on the implemented endpoints.

### Shopping Cart
- Manage shopping cart items.
- Add and retrieve cart items, depending on the implemented endpoints.

### User Authentication
- User registration.
- User login.

### Orders
- Create orders.
- Retrieve orders.
